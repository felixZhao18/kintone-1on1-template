# kintone 1on1面談ログ アプリ設計・設定ガイド

本リポジトリは、kintone上で「個人のプライバシー保護（心理的安全性）」と「人事データとしての蓄積・活用（適材適所・組織改善）」を両立させる1on1面談ログアプリの設計情報およびテンプレートを管理するためのものです。

---

## 1. アプリの概要

- **目的**: 1on1面談の記録・共有、次回アクションの追跡、組織全体の課題分析
- **特徴**: 直感的なUIと、厳格なレコードアクセス権限設定による心理的安全性の確保

---

## 2. フィールド構成

| フィールド名 | フィールドタイプ | 概要・設定のポイント |
| :--- | :--- | :--- |
| **面談実施日** | 日付 | 面談を行った日付 |
| **対象者（メンティー）** | ユーザー選択 | 面談を受ける社員（1名指定） |
| **面談者（メンター）** | ユーザー選択 | 面談を行った上司・チーフ・役員（1名指定） |
| **面談区分** | ラジオボタン | 例：チーフ面談 / 役員面談 / 定期1on1 |
| **対話テーマ** | チェックボックス | 例：キャリア・挑戦 / 業務負荷・働き方 / 組織・現場改善 / その他 |
| **面談メモ・主な内容** | 複数行文字列 | 面談中の対話内容（本人の気付きや相談事項） |
| **会社への要望・改善アクション** | 複数行文字列 | 組織として対応・改善すべき事項（必要な場合のみ記入） |
| **次回フォロー事項** | 複数行文字列 | 次回までに相互に確認・実施するアクション |

---

## 3. 【最重要】アクセス権限の設定（心理的安全性の担保）

設定場所：`アプリの設定` ＞ `設定` タブ ＞ `アクセス権` ＞ `レコード`

以下の優先順位（上から順）でレコードアクセス権限を設定します。

| 優先度 | 条件・対象 | 閲覧 | 編集 | 削除 | 目的・運用上の理由 |
| :---: | :--- | :---: | :---: | :---: | :--- |
| **1** | `[対象者] ＝ (ログインユーザー)` | ○ | × | × | 社員本人は過去の自分の記録を閲覧可能（改ざん不可） |
| **2** | `[面談者] ＝ (ログインユーザー)` | ○ | ○ | × | 面談を実施した面談者のみが記載・編集可能 |
| **3** | `[人事統括グループ]` | ○ | ○ | ○ | 全体を統括管理する人事担当者のみ全件閲覧・管理 |
| **4** | `Everyone`（その他全員） | × | × | × | 第三者はデータの存在自体閲覧不可にする |

---

## 4. 運用・集計のガイドライン

1. **変更履歴の保持**  
   kintone標準機能の「レコードの変更履歴記録」を有効化し、労務管理上の客観的エビデンスとして保持します。
2. **全社集計・傾向分析（匿名化）**  
   人事管理者アカウントにてkintoneの「グラフ機能」を活用し、個人情報を除外した状態（対話テーマ別の件数、部署別の実施率など）で経営陣にレポーティングを行います。

---

## 5. テンプレートの適用方法（導入手順）

1. 本リポジトリ内の `kintone-1on1-template.zip`（※用意されている場合）をダウンロードします。
2. kintoneの `システム管理` ＞ `アプリテンプレート` ＞ `読み込み` からzipファイルをアップロードします。
3. `アプリを追加` ＞ `テンプレートから作成` にて本アプリを作成します。
